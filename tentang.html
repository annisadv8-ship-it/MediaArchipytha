Tentang Media

Misi Arsitek Muda adalah media pembelajaran interaktif Teorema Pythagoras untuk siswa SMP Kelas 8 dengan pendekatan Discovery Learning.

Cara Menggunakan

  1. Mulai dari Kantor Proyek, lalu kerjakan Proyek 1 sampai 3 secara berurutan.
  2. Selesaikan Lapangan Proyek untuk membuka Ujian Sertifikasi.
  3. Gunakan tombol A- dan A+ untuk mengatur ukuran teks, dan Mode Kontras untuk tampilan lebih jelas.
  4. Tekan tombol Bacakan untuk mendengarkan soal.
  5. Progres tersimpan otomatis. Tekan Reset Progres untuk mengulang dari awal.
